# Design references

This redesign adapts structural ideas rather than copying source code or visual assets.

- [Stanford Autonomous Systems Lab — Research](https://stanfordasl.github.io/research/): numbered research thrusts, large editorial headings, representative visual plus long-form explanation.
- [Stanford Multi-robot Systems Lab — News](https://msl.stanford.edu/news/): year rail, continuous vertical timeline, compact date/category/content rows.
- [Stanford Multi-robot Systems Lab — Publications](https://msl.stanford.edu/publications/): search-first publication index, year rail, seamless records separated by rules.

The DTPLab color system, typography, content, public URLs, data sources, and browser API remain project-specific.
